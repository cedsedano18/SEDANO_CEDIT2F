HOW TO RUN:
1. Extract the ZIP file.
2. Open the extracted folder in PyCharm.
3. Open any of the four Python files.
4. Click the Run button.
5. Run each file separately.

ALGORITHMS FOLLOWED:

ARRAY
- Append S, E, D, A, N, O.
- Remove the element at the last index until empty.
- Removal: O, N, A, D, E, S.

LINKED LIST
- Insert S, E, D, A, N, O at the end.
- Delete the first node until empty.
- Removal: S, E, D, A, N, O.

STACK (LIFO)
- Push S, E, D, A, N, O in that order.
- Pop the top element until empty.
- Removal: O, N, A, D, E, S.

QUEUE (FIFO)
- Enqueue S, E, D, A, N, O in that order.
- Dequeue the front element until empty.
- Removal: S, E, D, A, N, O.

Each data structure has its own Python file.
